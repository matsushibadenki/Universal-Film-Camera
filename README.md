# Universal Film Camera

Tauri 2をアプリシェルとし、Rustの共有Imaging Pipeline、Film Engine、OSネイティブのカメラ／エンコーダーを組み合わせるマルチプラットフォームカメラです。スチル撮影と動画収録の両方を対象にしています。

現在はmacOS native camera MVPとUniversal Imaging Pipeline／Film Profile基盤まで実装済みです。現在地と次の作業は [`docs/ROADMAP.md`](docs/ROADMAP.md)、全撮像工程の設計は [`docs/IMAGING_PIPELINE_ARCHITECTURE.md`](docs/IMAGING_PIPELINE_ARCHITECTURE.md)、撮影画面は [`docs/CAMERA_UI_LAYOUT.md`](docs/CAMERA_UI_LAYOUT.md)、開始手順と引き継ぎ事項は [`docs/IMPLEMENTATION_HANDOFF.md`](docs/IMPLEMENTATION_HANDOFF.md) を参照してください。
